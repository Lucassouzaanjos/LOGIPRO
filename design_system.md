Design System – LogiPro

1. Identidade visual

O LogiPro possui uma identidade visual voltada ao segmento de logística e gestão de entregas.

A interface foi desenvolvida com uma proposta moderna, profissional e intuitiva, priorizando a organização das informações e a facilidade de navegação.

O design utiliza tons de azul como elementos principais, transmitindo confiança, tecnologia e profissionalismo.

2. Paleta de cores

A identidade visual utiliza principalmente tons de azul, branco e cinza, com cores complementares para indicar diferentes situações do sistema.

Cor Aplicação
Azul principal Botões, destaques e elementos de navegação
Azul secundário Ícones e detalhes da interface
Branco Cards, painéis e áreas de conteúdo
Cinza claro Fundos e divisões de áreas
Cinza escuro Textos e títulos
Verde Indicadores positivos e entregas concluídas
Amarelo/Laranja Situações pendentes
Vermelho Erros e alertas

Os códigos HEX exatos devem ser preenchidos conforme as variáveis de cores definidas no arquivo CSS do projeto.

3. Tipografia

A tipografia da aplicação busca garantir legibilidade e organização visual.

São utilizados diferentes níveis de texto:

Títulos principais: utilizados para identificar as páginas e seções.
Subtítulos: apresentam informações complementares.
Textos auxiliares: utilizados em descrições, orientações e informações secundárias.
Botões e indicadores: utilizam textos de fácil identificação.

A hierarquia tipográfica ajuda o usuário a identificar rapidamente as informações mais importantes.

4. Espaçamentos e organização

A interface utiliza espaçamentos para separar os elementos e evitar excesso de informações visuais.

As principais decisões de organização são:

Margens internas nos cards e painéis.
Espaçamento entre campos de formulários.
Separação visual entre títulos e conteúdos.
Organização de informações em grades.
Utilização de tabelas para apresentação de dados.
Alinhamento dos elementos de navegação. 5. Componentes visuais
Sidebar (menu lateral)

Menu responsável pela navegação entre os módulos da aplicação.

Apresenta as opções:

Dashboard.
Entregas.
Clientes.
Entregadores.
Financeiro.
Cotação de frete.
Rastreamento.
Topbar (barra superior)

Apresenta o título da página atual, a data, o avatar do usuário e os controles de notificação e encerramento de sessão.

Cards de indicadores

Utilizados no Dashboard e no módulo Financeiro para apresentar informações resumidas, como quantidade de entregas, entregadores ativos, receitas e despesas.

Tabelas

Utilizadas para organizar informações de entregas, clientes, entregadores e despesas.

Botões

Possuem diferentes finalidades:

Botões principais para ações importantes.
Botões secundários para navegação.
Botões de exclusão para gerenciamento de registros.
Formulários

Utilizados para cadastro, autenticação, cotação de frete, registro de despesas e rastreamento.

Modais

Janelas sobrepostas utilizadas para cadastrar clientes e entregadores sem precisar sair da página atual.

Notificações (Toast)

Mensagens temporárias que informam o resultado das operações realizadas, como cadastros, exclusões e consultas.

Indicadores de status

Identificam visualmente a situação das entregas:

Pendente.
Em trânsito.
Entregue. 6. Iconografia

A aplicação utiliza a biblioteca Lucide Icons, que disponibiliza ícones vetoriais para representar visualmente as funcionalidades.

Exemplos de ícones utilizados:

Package: identificação do sistema.
Layout Dashboard: painel principal.
Truck: entregas e transporte.
Users: entregadores.
Building 2: clientes.
Wallet: financeiro.
Calculator: cotação de frete.
Map Pin: rastreamento.
Bell: notificações.
Log Out: encerramento de sessão.

7. Responsividade

O sistema foi desenvolvido considerando diferentes tamanhos de tela.

A organização responsiva busca permitir o acesso às funcionalidades em computadores, tablets e dispositivos móveis.

O menu lateral possui um controle específico para navegação em dispositivos móveis.

As tabelas utilizam áreas com rolagem horizontal quando necessário, evitando que as informações ultrapassem os limites da tela.

8. Experiência do usuário (UX)

As principais decisões de experiência do usuário são:

Navegação centralizada em um menu lateral.
Identificação clara de cada módulo.
Formulários organizados por finalidade.
Mensagens de confirmação e erro.
Indicadores visuais para facilitar a interpretação dos dados.
Padronização dos componentes.
Organização das informações em painéis e tabelas. 9. Objetivo do Design System

O Design System do LogiPro tem como objetivo manter a consistência visual da aplicação, facilitar a identificação das funcionalidades e proporcionar uma experiência de navegação simples, organizada e intuitiva.
