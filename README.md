LogiPro – Sistema de Gestão Logística

1. Nome do projeto

LogiPro – Sistema de Gestão e Rastreamento de Entregas

2. Descrição do problema identificado

A gestão de entregas e operações logísticas pode se tornar complexa quando as informações são controladas manualmente ou estão distribuídas em diferentes ferramentas. Isso dificulta o acompanhamento dos pedidos, o gerenciamento de clientes e entregadores, o controle financeiro e a consulta do andamento das encomendas.

Além disso, a falta de centralização das informações pode ocasionar erros, atrasos e dificuldades na organização das operações.

Diante desse cenário, surgiu a proposta de desenvolver o LogiPro, uma aplicação web que reúne funcionalidades essenciais para facilitar o gerenciamento logístico e o acompanhamento de entregas.

3. Objetivo da aplicação

O objetivo do LogiPro é oferecer uma plataforma de gestão logística que permita organizar e acompanhar as principais atividades de uma operação de entregas em um único ambiente.

A aplicação busca facilitar o controle de pedidos, o gerenciamento de clientes e entregadores, a realização de cotações de frete, o acompanhamento de encomendas e a administração financeira.

Dessa forma, pretende proporcionar mais organização, praticidade e eficiência na gestão das operações logísticas.

5. Tecnologias utilizadas

O desenvolvimento do LogiPro utiliza as seguintes tecnologias:

HTML5: estruturação das páginas e dos elementos da aplicação.
CSS3: estilização, organização visual e responsividade da interface.
JavaScript: implementação das funcionalidades, validações, interações e manipulação dos dados.
Supabase: banco de dados e serviços de autenticação dos usuários.
Lucide Icons: biblioteca de ícones utilizada na interface.
Git e GitHub: versionamento e hospedagem do código-fonte.
GitHub Pages: publicação da aplicação web.

Autenticação de usuários

Encerramento de sessão.

7. Instruções básicas de utilização

Para utilizar o LogiPro, siga as etapas:

Acesse a aplicação pelo link disponibilizado no GitHub Pages.
Na tela inicial, clique em Criar minha conta para realizar o cadastro.
Informe seu nome completo, e-mail e senha.
Após o cadastro, acesse a plataforma utilizando suas credenciais.
No Dashboard, visualize os indicadores gerais da operação.
Utilize o menu lateral para acessar os módulos disponíveis.
Cadastre clientes e entregadores para organizar sua operação.
Acesse a opção Cotação de frete para simular o valor de uma entrega.
Após realizar uma cotação, utilize a opção Solicitar entrega para registrar um pedido.
Consulte as entregas cadastradas no módulo Entregas.
Utilize o código gerado para consultar o andamento da encomenda na opção Rastreamento.
No módulo Financeiro, registre despesas e acompanhe os resultados mensais.

Observação: O cálculo do frete é uma simulação ilustrativa, baseada em valores definidos no sistema. O rastreamento apresenta as informações de status registradas na aplicação, não sendo um rastreamento GPS em tempo real.

Considerações finais

O LogiPro foi desenvolvido com a proposta de facilitar a organização e o gerenciamento de operações logísticas por meio de uma plataforma web intuitiva e funcional.

A aplicação integra diferentes recursos em um único ambiente, contribuindo para o controle de entregas, clientes, entregadores e informações financeiras.

O projeto também permite aplicar conhecimentos de desenvolvimento web, integração com banco de dados, autenticação de usuários e organização de interfaces.
